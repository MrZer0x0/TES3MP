# Что перенесено из свежего OpenMW для macOS ARM64

Из `openmw-master` перенесена сама архитектура CI, а не современные бинарные зависимости:

- отдельные скрипты установки, конфигурации и упаковки;
- нативный runner `macos-14-arm64`;
- явные `CMAKE_OSX_ARCHITECTURES=arm64` и `CMAKE_OSX_DEPLOYMENT_TARGET`;
- сборка установочного пакета через CPack `DragNDrop`;
- ad-hoc codesign после упаковки;
- сохранение DMG в GitHub Actions artifacts.

Современный пакет `openmw-deps` не подключён целиком, поскольку он рассчитан на новую ветку OpenMW, Qt 6 и современные версии FFmpeg/других библиотек. Старый TES3MP 0.47 может быть несовместим с их API.

MyGUI 3.4.3 собирается отдельно из исходников, поскольку формула Homebrew `mygui` отсутствует.
