# Исправление GitHub Actions для Linux / Steam Deck

Добавлен пакет `libluajit-5.1-dev`, необходимый модулю `FindLuaJit.cmake` и подсистеме `apps/openmw-mp`.

Также Linux job теперь всегда создаёт и загружает артефакт:

- при успешной сборке внутри находится готовый `tar.gz`;
- при ошибке внутри остаются `BUILD_INFO.txt`, `CMakeCache.txt` (если создан) и список файлов каталога сборки.

Это позволяет видеть ссылку в секции **Artifacts** даже при ошибке компиляции или конфигурации.
