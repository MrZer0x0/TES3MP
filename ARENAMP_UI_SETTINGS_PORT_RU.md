# ArenaMP — UI, settings and log path restoration

## Исправлено

- Ползунок GUI scaling перенесён в отдельную вкладку `GUI`; он больше не перекрывает Water.
- Все страницы главного окна настроек получили одинаковую рабочую область.
- Вкладки Video, Water и Lights переразложены по сетке без выхода за границы.
- Для воды восстановлены четыре уровня RTT: 256, 512, 1024 и 2048.
- Сохранены горячее применение GUI scale и расширенных параметров воды.
- Основой оставлен пользовательский канонический `settings-default.cfg`.
- В `[Water]` подтверждено `refraction scale = 3`.
- Восстановлена Zero Custom логика путей:
  - portable `userdata` рядом с исполняемым файлом, если каталог доступен;
  - отдельные TES3MP config/data paths вместо OpenMW;
  - settings path `Documents/NirnSave/OpenMW/settings.cfg`, если он уже существует, иначе `userdata/settings.cfg`;
  - логи сохраняются в тот же TES3MP `userdata`;
  - поддержаны `local-config=true` и цепочки `config=`;
  - `settings-default.cfg` используется как резерв, если `defaults.bin` отсутствует;
  - первичный settings.cfg получает разрешение и GUI scale при первом запуске.

## Проверка

- Проверены все MyGUI layout/XML и Qt `.ui` файлы проекта.
- Все виджеты, запрашиваемые `settingswindow.cpp`, присутствуют.
- В repaired tabs нет элементов за границами контейнеров.
- В конфиге нет дублирующихся ключей.
- `defaults.bin` проверен обратным Base64-декодированием.

## Установка

Архив changed-files распаковывается в корень репозитория. После этого нужна пересборка.
Полный архив содержит уже объединённое дерево исходников.
