--- v47 launcher local-server Play flow ---

- Removed the temporary Host Mode / Close Host Mode button and its extra panel.
- Play now uses the local LAN server endpoint when either Auto-start server or Auto restart and backup is enabled.
- Auto restart can therefore select the local-server flow even when Auto-start is not checked.
- Local hosting no longer overwrites the remote endpoint stored in build.ini.
- An explicit [Server] port entry in build.ini disables and clears both local-server checkboxes.
- A build.ini without an explicit port keeps local-server controls available; launcher-generated local-host manifests preserve the missing port entry.
- Wizard-generated manifests keep an explicit port and therefore remain fixed to their configured server endpoint.

--- v48 Host mode precedence fix ---

- Renamed "Auto-start server before connecting" to "Host mode".
- Host mode and Auto restart and backup are never disabled by an explicit port in build.ini.
- When either checkbox is enabled, Play uses the local LAN address and local server port.
- The local server is started when it is not already running; otherwise Play connects to the existing local server.
- Local hosting takes precedence over the build.ini endpoint and vanilla compatibility for that launch only.
- The distributed remote address, port and vanilla flag in an existing build.ini are preserved and are not replaced by the host machine's LAN endpoint.
