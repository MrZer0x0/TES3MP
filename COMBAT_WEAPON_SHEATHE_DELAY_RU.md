# ArenaMP — задержка уборки оружия NPC

Добавлена задержка перед уборкой оружия после завершения боевого AI-пакета.

## Поведение

- NPC после выхода из боя сохраняет оружие в руках ещё заданное время.
- Значение по умолчанию: 2 секунды.
- Если бой начинается повторно, ожидающая уборка оружия немедленно отменяется.
- Игрок не затрагивается.
- Заклинания не задерживаются: изменение относится только к оружию.

## Настройка

В секции `[Game]` файла настроек:

```ini
combat weapon sheathe delay = 2.0
```

`0` отключает задержку.
