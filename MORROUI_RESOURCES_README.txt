MorroUI in this port mostly replaces existing OpenMW/TES3MP resource filenames under files/mygui/
rather than adding many new uniquely named files.

So the MorroUI resources are present mainly as replacement files such as:
- files/mygui/openmw_inventory_window.layout
- files/mygui/openmw_trade_window.layout
- files/mygui/openmw_spell_window.layout
- files/mygui/openmw_list.skin.xml
- files/mygui/openmw_resources.xml
- files/mygui/openmw_quickloot.layout

If you want to inspect only the resource delta against the original TES3MP tree,
use the separate tes3mp_morroui_resources_overlay.zip archive.
