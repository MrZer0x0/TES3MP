# Обновление GUI, HUD, Quick Loot, ownership и чата

- Вкладка GUI выровнена и разбита на HUD, Interaction и Camera.
- Иконки оружия/заклинания переходят на 40% только когда соответствующая полоса выносливости/маны фактически скрыта.
- Для чужих предметов используется `files/vfs/textures/ownership.dds` вместо обычного прицела.
- Чат оформлен компактным чёрным боксом у нижней границы; в режиме ввода разворачивается.
- Quick loot: W/S или стрелки — выбор, E/Enter — взять, Q — закрыть, F — обычный режим.
- D не удаляет предметы локально: это небезопасно для сетевой синхронизации TES3MP.
