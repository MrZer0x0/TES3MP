# Интеграция libpiper в ArenaMP

## Что добавлено

- Локальный офлайн-синтез входящих сообщений игроков через динамически загружаемый `libpiper`.
- Автоматическое определение русского и английского текста, включая последовательный синтез смешанных RU/EN-фрагментов.
- Выбор отдельной мужской или женской модели по `ESM::NPC::isMale()`.
- Расовые профили скорости и мягкая PCM-обработка тембра для нордов, орков, данмеров, альтмеров, босмеров, каджитов и аргониан.
- Стабильная небольшая вариация скорости по GUID персонажа.
- Фоновый поток синтеза и ограниченные очереди, не блокирующие игровой поток.
- Фильтрация команд, URL, цветовой разметки и слишком длинных сообщений.
- Передача готового mono float PCM в штатный поток речи `SoundManager::say()`.
- Позиционирование звука у головы персонажа, стандартное затухание голоса и существующий анализ громкости для анимации речи.
- Настройки `[Chat TTS]` в `files/settings-default.cfg`.
- Сборка и упаковка Piper 1.6.0, ONNX Runtime, espeak-ng-data и четырёх голосов в Windows/Linux/macOS release workflow.

## Основные файлы

- `apps/openmw/mwmp/tts/ChatTtsManager.*`
- `apps/openmw/mwmp/tts/PiperApi.*`
- `apps/openmw/mwmp/tts/PcmDecoder.*`
- `apps/openmw/mwmp/tts/LanguageDetector.*`
- `CI/tts/prepare-piper.sh`
- `files/tts/`

## Сборка

Release workflow автоматически выполняет перед конфигурацией ArenaMP:

```bash
CI/tts/prepare-piper.sh <рабочий-каталог> files/tts <windows|linux|macos>
```

Для локальной Linux-сборки:

```bash
sudo apt-get install ninja-build patchelf
CI/tts/prepare-piper.sh /tmp/arenamp-piper files/tts linux
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

## Поведение при отсутствии TTS

Клиент не связан с Piper жёстко. Если библиотека, espeak-ng-data или модель отсутствуют, ArenaMP продолжает работать, а ошибка записывается в лог при первой попытке озвучивания.

## Лицензии голосов

Лицензия движка и лицензии голосовых моделей независимы. Скрипт сохраняет `MODEL_CARD` каждого голоса рядом с моделью. Перед публичным распространением архива необходимо проверить условия всех четырёх карточек модели.

## Выполненные локальные проверки

- компиляция и запуск теста определения RU/EN;
- компиляция `PcmDecoder.cpp`;
- компиляция ABI-обёртки `PiperApi.cpp` с SDL-заглушкой;
- проверка Bash-синтаксиса `prepare-piper.sh`;
- проверка YAML release workflow;
- проверка всех точек интеграции скриптом `CI/tts/check-integration.py`.

Полная сборка ArenaMP и самого libpiper в текущем изолированном окружении не выполнялась: здесь отсутствуют системные OpenMW/OSG-зависимости и сетевой доступ Git/CMake. Именно поэтому в архив добавлена воспроизводимая CI-сборка для GitHub Actions.
